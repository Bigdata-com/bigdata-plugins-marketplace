# Catalyst monitor — report template

Follow this structure. Keep the section order. Every catalyst carries a date or window — where the date is unknown, write the expected quarter and mark it as undated. Add inline citations `[1]`, `[2]` immediately after claims, hyperlinked to the document URL.

---
