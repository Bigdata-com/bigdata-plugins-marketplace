# Peer comparables — report template

Follow this structure. Keep the section order. Every peer appears in every table with the same metrics from the same period — where a figure is unavailable, write "n/a" rather than dropping the peer. Add inline citations `[1]`, `[2]` immediately after claims, hyperlinked to the document URL.
